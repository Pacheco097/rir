# Backend — API REST (Laravel)

Instruções de instalação e execução no [README principal](../README.md).
Arquitetura, ERD e lista de endpoints em [`docs/ARQUITETURA.md`](../docs/ARQUITETURA.md).

Comandos úteis:

```bash
php artisan serve                 # sobe a API em :8000
php artisan migrate:fresh --seed  # recria o banco com dados fictícios
php artisan test                  # testes
php artisan route:list --path=api # lista os endpoints
vendor/bin/pint                   # formatação
```
